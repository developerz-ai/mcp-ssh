# 1.4.0 — 2026-07-21

Audit fixes across files, jobs, OAuth and auth, a `/healthz` endpoint, and the job engine split into focused modules.

### Added

- `/healthz` endpoint (#22).

### Changed

- `redirect_uri` is bound to the registered client, an empty `Host` is rejected, and a non-loopback bind requires `MCP_SSH_ALLOWED_HOSTS` (#21).
- `JobRepo`, `JobStatus` and the jobs module splits (#23).

### Fixed

- File operations are bounded in memory and wall-clock time; `move` never overwrites (#18).
- A process group already gone before `SIGTERM` is reported as killed (#19).
- Expired tokens are swept, token pairs are written atomically, and legacy databases migrate (#20).
- Job-dir path resolution (#22).
