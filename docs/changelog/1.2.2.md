# 1.2.2 — 2026-06-27

Clients no longer fail `job`/`file` with `invalid type ... expected string or map`.

### Fixed

- The `action` enum is inlined in the tool schema instead of a `$ref` into `$defs`, which several clients drop.
- A non-string or missing `job` `action` falls back to the read-only `list`.
