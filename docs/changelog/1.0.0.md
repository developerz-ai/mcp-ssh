# 1.0.0 — 2026-06-26

First stable release: an MCP server giving an agent shell, file and job access to one host over authenticated Streamable HTTP.

### Added

- Three tools — `bash`, `job`, `file` — over `/mcp`, behind OAuth 2.1.
- Human-readable job ids (#9).
- `bin/mcp-token` for headless clients (#10).
